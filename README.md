# MC-Client

**Saiter Craft** — это кастомная Minecraft-сборка, включающая тщательно подобранные моды, индивидуальные конфигурации и скрипт для автоматического обновления сборки. Цель проекта — обеспечить стабильный и интересный игровой опыт с возможностью быстрого обновления на стороне клиента.

---
> ⚠️ Обратите внимание: для корректной работы обновляющего скрипта требуется установленный `curl`, а также доступ к интернету, А ТАКЖЕ УМЕНИЕ НАЖАТЬ КНОПКУ ENTER.
---
